A phone system for small businesses

Traffic Control runs a small business's phones. You decide where calls go on one screen, then answer them in the browser with a headset. It isn't live yet, and it's invite only.

The phone menu and ring groups are set up on one screen. After hours, callers hear a different greeting. Voicemail comes with a transcript, so you can read it before you call back.

Miss a call and it can text the caller back, so they don't just call the next business. Each customer gets one text thread, and the whole team can see it.

Call tracking ties each call to where it came from. Your site shows every visitor their own number, so you can see which ad and keyword led to a call. It also shows whether anyone picked up.

Other apps can put its screens inside their own, with an API key and webhooks. One sign-in can cover more than one business.
