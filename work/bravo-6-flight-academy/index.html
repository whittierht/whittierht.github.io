135 pages off WordPress

A Divi site rebuilt as 135 static pages, generated by two Python scripts.

Every page sits in its own folder, so clean URLs work on ordinary shared hosting with no rewrite rules.

Both tools in the Resources menu are new. Is It Flyable Today checks live airport weather against the school's own minimums. The training area map draws the practice areas over an FAA sectional chart.

Rexburg and Pocatello each have their own page, with schema for that location. There's more on those on the local SEO page.
