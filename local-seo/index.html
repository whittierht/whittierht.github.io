02 Audits

What I check

My crawler checks the same things on every site: status codes, whether each page can be indexed, canonicals, schema types and redirect chains. It runs them against every sitemap the site lists.

Titles and descriptions get measured in pixels, because Google cuts them off by width.

Then I read the schema by hand, since a graph can pass validation and still describe the wrong thing.

03 Town pages

A page for each town

Bravo 6 Flight Academy trains pilots in Rexburg and Pocatello. Each town has its own page. The schema on each one has that location's hours and coordinates, and names the airport.

The Rexburg page opens with where the school is, at Rexburg-Madison County Airport on the west side of town.

04 Migrations

Moving a site without losing rankings

Outdoors for Youth was on Wix, with the content locked inside iframes. I rebuilt it as 22 hand-coded pages and matched every slug to the old site, so the rankings carried over. It's been live since July.

Bravo 6 was a Divi site. Two Python scripts now build it as 135 static pages, each in its own folder so the URLs stay clean on shared hosting. It moved onto the main domain in August.

05 Page builders

Fixing what a builder got wrong

Nadia's Dog Nanny Services in Phoenix was on GoDaddy's builder, which wrote its own schema. That schema pointed at a made-up domain. Her sitemap had junk URLs in it, and the titles were double-encoded.

Now it's 14 hand-coded pages with one schema graph each. Her seven services are listed as an offer catalog with verified prices. Every certification in the schema is real, and there's no review-star markup.

07 Enterprise

SEO at national scale

Not every account is local. One is a national payments processor and its co-branded programs. Their teams take the work live, so I don't name it here.

  • Keyword architecture

    Every indexable page mapped to one target keyword, with a call on each URL: keep, rewrite, merge, redirect or retire.

  • Schema and metadata at scale

    A JSON-LD graph for every indexable page across the account, plus a rewritten title and description. All of it validated before handover.

  • Fixing an orphaned library

    A whole article section had no crawlable path into it. The controls that opened each category were buttons, and Googlebot doesn't click buttons.

  • Partner bank web audits

    A bank's public web presence scored against a fixed framework, then a gap analysis and a roadmap. The crawl can run again for the next partner.
