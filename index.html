04 Enterprise

SEO at national scale

  1. Site-wide keyword architecture

    Every indexable page mapped to one target keyword, with a retain, optimize, consolidate, redirect, or decommission call on each URL.

  2. Resource and support center rebuilds

    Two pitches delivered as working mockups instead of slides, built from a harvested library of the client's real content.

  3. Content plan restructure

    One page type per week per account. The template gets built once and rolls across every page of that type.

  4. Partner bank web audits

    Six-dimension scoring of a bank's public web presence, delivered as a scorecard, gap analysis, and roadmap. The crawl rig is re-runnable for the next partner.

  5. Personalized marketing toolkit

    A marketing page for merchants. A code in the URL swaps in that merchant's own QR code and matches the downloadable assets to their account.
